# Midlands Academic Excellence Hub website

Static website for Midlands Academic Excellence Hub.

## Publish with GitHub Pages

1. Upload all files and the `assets` folder in this directory to the root of the `school-website` repository.
2. In GitHub, open **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then click **Save**.
5. GitHub will publish the site at `https://midlands-academic-excellence-hub.github.io/school-website/`.

The enquiry form is a front-end demonstration only. Connect it to an email/form provider before collecting real enquiries.
